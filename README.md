# Fena Media Manager – Documentation

User documentation for **Fena Media Manager 1.0.0**, a WordPress plugin that adds
virtual folders to the media library.

**Read online:** https://nedzadomeragic1973-ops.github.io/fena-media-manager-docs/

This repository contains only the static documentation website (HTML, CSS, a small
vanilla JavaScript file and screenshots). It has no build step and no external
dependencies, and it does not contain the plugin itself.

## Structure

```
index.html            Documentation (single page)
assets/css/docs.css   Styles
assets/js/docs.js     Mobile navigation, active chapter, screenshot loader
assets/images/        Screenshots and logo
```

## Updating screenshots

Replace a PNG in `assets/images/` with a file of the same name. No HTML change is
needed; the page shows the image automatically.
